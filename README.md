# Princepo

Princepo помогает найти открытые запросы сайта и использовать их как операции через MCP. Он открывает страницу в браузере, собирает адреса её запросов `fetch` и XHR, а затем может сохранить выбранный адрес и повторять его по имени.

Это небольшая первая версия для **публичных данных**. Она работает только с GET-запросами и не умеет входить в аккаунты, выполнять действия на сайте или автоматически строить интеграцию по описанию. Сайт может не иметь подходящего открытого запроса, а найденный адрес со временем может измениться.

## Установка

Нужен Node.js 20 или новее.

```bash
npm install
npx playwright install chromium
```

На Linux при необходимости установите системные зависимости браузера командой `npx playwright install --with-deps chromium`.

## Через терминал

Из папки проекта:

```bash
node princepo.mjs inspect https://example.com
```

Команда выведет заголовок страницы и найденные запросы. Выберите подходящий адрес из результата и сохраните его:

```bash
node princepo.mjs save news https://example.com/api/news
node princepo.mjs list
node princepo.mjs call news
```

`news` — название операции. Адрес в примере условный: используйте тот, который действительно обнаружен на нужном сайте. Ответ ограничен одним мегабайтом.

## Подключение к MCP

Добавьте в настройки своего MCP-клиента запись, заменив путь на расположение файла у себя:

```json
{
  "mcpServers": {
    "princepo": {
      "command": "node",
      "args": ["/полный/путь/к/princepo/princepo.mjs", "serve"]
    }
  }
}
```

После перезапуска клиента доступны инструменты `inspect_site`, `save_operation`, `list_operations` и `call_operation`. Например: «Открой страницу, найди запрос со списком новостей и сохрани его как `news`».

Сохранённые операции находятся в `~/.princepo/operations.json`. Другую папку можно указать переменной окружения `PRINCEPO_HOME`. Пароли и ключи в адреса передавать не нужно: параметры с распространёнными названиями секретов программа отклоняет.

## Проверка

```bash
npm test
```

Тест поднимает локальный сайт и проверяет браузер, MCP и сохранение запроса; внешние сервисы не нужны.
